# 🚌 ระบบจองที่นั่งรถบัสแบบ Real-time

ระบบจองที่นั่งรถบัสออนไลน์ รองรับการทำงานร่วมกันระหว่างครูและนักเรียนอย่างเป็นระบบ พัฒนาโดยใช้ **Google Apps Script** ร่วมกับ **HTML/CSS/JavaScript** และเชื่อมต่อฐานข้อมูลโดยตรงกับ Google Sheets

## 📊 คุณสมบัติของระบบ
- **Real-time Synchronization:** ดึงและอัปเดตสถานะที่นั่งโดยอัตโนมัติทุก ๆ 3 วินาที
- **Role-based Visualization:** แสดงสีแยกตามสิทธิ์การจองชัดเจน (นักเรียน = สีเขียว 🟩 | ครู = สีเหลือง 🟨)
- **Live Dashboard:** แสดงภาพรวมจำนวนที่นั่งที่จองแล้ว และจำนวนที่นั่งว่างที่เหลืออยู่ตลอดเวลา
- **Timeout Counter:** มีระบบนับเวลาถอยหลัง 1 นาที 30 วินาที หากเลือกที่นั่งแล้วไม่กดยืนยัน ระบบจะคืนสิทธิ์เบาะว่างให้ผู้อื่นทันที
- **Data Validation:** ป้องกันการกรอกชื่อซ้ำ และป้องกันปัญหากดจองที่นั่งซ้ำซ้อนในเวลาเดียวกัน

## 🛠 เทคโนโลยีที่ใช้
- **Backend:** Google Apps Script (GAS)
- **Frontend:** HTML5, CSS3 (Grid Layout & Custom Properties), Vanilla JavaScript
- **Database:** Google Sheets (แท็บ `BookingData`)
- **Fonts:** Prompt (Google Fonts)
