# 🚌 ระบบจองที่นั่งรถบัสแบบ Real-time

ระบบจองที่นั่งรถบัสออนไลน์ รองรับการทำงานร่วมกันระหว่างครูและนักเรียน พัฒนาโดยใช้ **Google Apps Script** และ **HTML/CSS/JavaScript** เชื่อมต่อฐานข้อมูลด้วย Google Sheets

## 📊 คุณสมบัติของระบบ
- ระบบจองที่นั่งและแสดงผลแบบ Real-time (อัปเดตทุก 3 วินาที)
- แยกระดับสิทธิ์และสีการจอง (นักเรียน = สีเขียว 🟩, ครู = สีเหลือง 🟨)
- มีระบบ Dashboard สรุปภาพรวมที่นั่งว่างและจำนวนผู้จองแยกตามสิทธิ์
- ระบบนับเวลาถอยหลัง (Timeout Counter) 1.30 นาที หากเลือกที่นั่งแล้วไม่ยืนยัน ระบบจะคืนสิทธิ์ให้ผู้อื่นทันที
- ป้องกันการจองชื่อซ้ำ และป้องกันการกดจองที่นั่งซ้ำซ้อน

## 🛠 เทคโนโลยีที่ใช้
- **Backend:** Google Apps Script (GAS)
- **Frontend:** HTML5, CSS3 (Grid Layout & Custom Properties), Vanilla JavaScript
- **Database:** Google Sheets (แท็บ `BookingData`)
- **Fonts:** Prompt (Google Fonts)
